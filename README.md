# cn.oakdb.cadmouse

从[CadMousePro](https://mouse.globalcode.info/v_0/cadMousePro.xhtml)项目改造而来的3DConnexion CadMouse驱动及设置工具，解决有线连接问题的方案启发自[Ask Ubuntu](https://askubuntu.com/questions/1201793/cadmouse-pro-wireless-stops-working-2-3-secs-after-plugging-in-via-usb-18-04-3)。

支持的设备型号及设备ID：

- CadMouse Pro: VID256F_PIDC656
- CadMouse Compact: VID256F_PIDC655
- CadMouse Compact Wireless: VID256F_PIDC658
- CadMouse Pro Wireless: VID256F_PIDC654
- CadMouse Pro Wireless (USB-C): VID256F_PIDC668
- CadMouse Pro Wireless Left: VID256F_PIDC657
- CadMouse: VID256F_PIDC650
- CadMouse Wireless: VID256F_PIDC651
- Universal Receiver: VID256F_PIDC652

在Deepin 25/UOS 25 AMD64架构上测试通过。
